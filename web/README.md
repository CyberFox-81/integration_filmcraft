## Embedding bridge

Started with `?host=parent` inside an iframe, FilmCraft talks to its parent window with `postMessage`. It only accepts messages from the parent window on its own origin, and only sends to that origin. Every message is a plain object with a `type`:

| Message | Direction | Fields | Meaning |
|---|---|---|---|
| `filmcraft:ready` | FilmCraft → parent | `version` | The app is listening; send a file now. |
| `filmcraft:open` | parent → FilmCraft | `name`, `bytes` (`ArrayBuffer` or `Uint8Array`) | Open this file, as File › Open would. |
| `filmcraft:save` | FilmCraft → parent | `name`, `bytes` (transferred `ArrayBuffer`) | A file FilmCraft would otherwise download: Save, Save As or Export. `name` is a file name, or a path the parent picked. The parent stores the file and reports success or failure itself. |
| `filmcraft:dirty` | FilmCraft → parent | `dirty` (boolean) | Unsaved changes appeared or went away. |
| `filmcraft:failed` | FilmCraft → parent | `error` | The app couldn't start (for example, no WebGPU or WebGL2). |

Files the parent sends keep its path under `/host` in FilmCraft's virtual file table, so a saved project refers to its media by their paths on the parent's side. Before a project opens, FilmCraft asks for the media it refers to that aren't there yet:

| Message | Direction | Fields | Meaning |
|---|---|---|---|
| `filmcraft:need` | FilmCraft → parent | `paths` | Files an opened project refers to (its media). |
| `filmcraft:file` | parent → FilmCraft | `path`, `blob` or `error` | One of them, or why it can't be had (that media stays offline). |

`filmcraft:open` also carries `path` (the file's path on the parent's side) and sends a `Blob` rather than bytes. A saved project's `name` is the parent's path when it lives there; a new project or an export goes by its file name, and the parent asks where it goes. In host mode neither the demo project nor the recovery snapshot opens, and the parent guards leaving the page.

Without `?host=parent`, FilmCraft behaves exactly as upstream: saved files download.
